# VibeMemory Examples

This directory contains runnable examples for each integration method.

## Quick Start

```bash
python examples/quickstart.py
```

## By Integration

| File | Integration | Description |
|------|------------|-------------|
| `quickstart.py` | Python SDK | 5-minute quickstart with store/recall |
| `langchain_example.py` | LangChain | Complete LangChain agent with memory |
| `openai_agents_example.py` | OpenAI Agents SDK | Agent with VibeMemory tools |
| `mcp_example.py` | MCP Server | Client that calls MCP tools |
| `http_example.py` | HTTP API | REST API usage with curl/requests |
| `reflect_example.py` | Reflect | Cross-memory reasoning with LLM |
